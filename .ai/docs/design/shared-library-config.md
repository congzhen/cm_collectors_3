# 文件库公共基础配置

## 范围与交付

一期：基础展示配置跟随，完成后独立 Git 提交。二期：导入规则、资源刮削参数跟随，再独立提交。没有模板系统、标签复制或标签同步。

用户显式将当前参数设为公共配置。各分组只有一份公共配置；旧库默认独立，新库可选择跟随。公共配置通过“打开公共配置”独立弹窗更新，保存前列出关联库。停止跟随时保留当前生效参数。

## 边界

- 共享字段由后端 `SharedConfigFields` 白名单定义，前端用同一份字段列表提取弹窗草稿。
- 片段预览生成方式与默认抽图间隔纳入基础展示公共配置；后台按视频所属库读取生效值。跟随时本库表单只读，公共设置更新不触发已有预览重建。
- 片段收藏打开方式 videoMomentOpenMode 纳入基础展示公共参数，默认 dialog，可选 page；跟随时锁定，退出跟随后支持保留公共值或恢复原库值。旧公共配置缺少该字段时保留本库原值，重新保存公共配置后再按新值覆盖。
- 标签和演员引用、目录、路径映射、自定义头像、封面预设列表及索引始终属于本库。
- 公共参数单独存储；跟随关系单独存储。升级只增加表，不批量重写旧配置。
- 普通读取按需叠加公共值，独立库保留原始 JSON 和空配置语义。
- 普通写入不更新公共配置；跟随中提交不同公共参数会被后端拒绝。
- 首页快捷调整明确提示关闭本库展示跟随；取消时恢复服务端生效值。
- 公共更新带版本校验，旧页面不能静默覆盖新版本。不提供删除公共配置入口。
- 启用、退出跟随和新建库关联均在事务内执行；删除空库清理跟随关系。
- 套用配置不自动启动任何导入、刮削或计划任务。当前页面切换文件库或重新加载时获取最新公共值。

## 验证

使用内存 SQLite 检查独立库不变、多个跟随库更新、本地引用保留、退出后保持参数、版本冲突、失败事务回滚、旧空配置语义。前端做类型检查、构建及交互测试。

开发前基线：`go test ./models ./processors ./controllers` 的 processors 包有已存在的 LogError 非常量格式串 vet 错误；`yarn.cmd type-check` 已存在 require、textAlign 和 coverAdjuster 显示模式类型错误。记录基线后以新增错误为回归判断，运行 Go 测试时可使用 `-vet=off` 单独确认测试结果。

一期提交：`89aafd8`。后端 models/processors/controllers 测试在 `-vet=off` 下通过；前端全量 96 项单元测试及 `yarn.cmd build-only` 通过。二期复查时修正了一期新增测试的确认框 mock 返回值类型，最终类型检查仅剩上述基线问题。

## 二期实现与边界

- 导入分组共享文件匹配、命名、剧集合并和 NFO 解析规则；封面预设索引、封面尺寸与目录属于本库。
- 刮削分组共享刮削器选择、并发、超时、重试和图片/NFO 保存参数；目录属于本库。保存和启用公共刮削配置时校验刮削器文件依赖，不启动浏览器。
- 资源导入／刮削页面复用同一公共配置控件；编辑公共参数时禁止执行任务。
- Go 刮削配置保留 concurrency 字段，防止执行前保存配置时丢失前端并发值。
- 手动任务在准备列表时固定目标库，在列表中深复制参数；关闭／重开后旧批次不再继续发起请求。正在处理的单条请求不强制中断。
- 计划任务继续使用既有 Config_ScanDisk / Config_Scraper 入口，一次读取完整生效参数后传给该批次所有文件；单资源刮削仍使用其独立操作参数，所依赖的导入配置通过公共解析入口读取。
- 公共配置异常不阻塞独立库保存；跟随库明确报错。三个分组的跟随状态相互独立。
- 未执行真实目录扫描、外站刮削或现有实例的数据库迁移，验证使用内存数据库和模拟请求；上线后仍需在测试实例人工验收实际页面及外部刮削器。

二期验证：后端 models/processors/controllers 测试（`-vet=off`）通过；前端全量 101 项单元测试及 `build-only` 通过。包括目录和标签引用隔离、三个分组独立、正常执行前保存、旧参数冲突、任务参数深复制、关闭重开隔离和公共配置损坏隔离。

## 公共配置独立弹窗

- 基础展示、导入规则、刮削参数统一通过“打开公共配置”进入独立弹窗，展示当前分组及跟随库列表。
- 跟随开启时，本库页仅显示目录、关联项等本库独立设置；关闭跟随时，本库页显示完整本库参数。状态加载失败时保留原有表单和重试入口，实际保存仍由后端校验。
- 弹窗深复制公共字段作为草稿，打开和取消不改变本库表单；创建时从当前本库参数提取公共字段，保存不会自动启用跟随。
- 保存前刷新影响范围并检查版本，冲突保留弹窗草稿；成功后只更新当前跟随库的公共值，保留本库独立字段的未保存修改。
- 本库保存和公共保存入口分开，公共弹窗开启期间禁止执行导入、刮削及本库保存。
- 验证：前端 105 项单元测试、生产构建通过，类型检查仅剩既有基线错误；三个分组均使用真实表单组件和模拟接口完成浏览器弹窗检查，未修改现有数据库。
