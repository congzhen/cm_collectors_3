# 视频采集排除规则

## 用户入口与行为

在“视频信息采集”设置全局规则，默认开启常见图片、网页、文本、字幕后缀排除；自定义后缀支持空格、中英文逗号或分号，忽略大小写及开头的点，保存时去重。最多 100 项，不接受路径和通配符。排除常见视频后缀时界面二次提醒。

规则只影响视频元数据探测，不影响资源入库、图片使用、实体文件或目录。未知后缀、无后缀、下载临时文件不会自动排除，探测报错本身不能作为非视频判断依据。

“采集失败文件”页包含失败和已排除两个视图，均在数据库端筛选后分页。支持当前页多选批量重试、人工排除，以及从已排除视图指定为视频并重试。部分失败会报告成功数和失败数。

保存规则立即影响查询与后续队列执行。不会因保存设置而扫描磁盘或启动全库重新探测。

## 历史整理

“按已保存规则整理历史记录”先按后缀展示全库影响数量，确认后每 200 条事务分批整理，可查看进度。仅清除规则匹配项的时长、探测状态和视频元数据，不删除文件、资源、分集，不清理人工补录元数据。

预览附带规则版本令牌；规则改变必须重新预览。整理期间改变规则会停止后续批次。运行进度保存在当前服务进程，服务重启后可再次执行整理，已完成批次不会重复处理。原有手动/计划补齐中的非视频纠正同样复用规则和分批整理。

## 存储和兼容

- `video_metadata_settings` 增加 `auto_exclude_non_video`（NULL 按开启处理，兼容旧配置）和 `excluded_extensions`。
- `resourcesDramaSeries` 增加 `video_metadata_classification`：`video` 人工指定视频，`nonvideo` 人工排除；`system`/`custom` 为可随规则撤销的自动分类。
- 新分集使用自动分类标识；实际原因根据当前规则计算，不依赖过期的布尔值。
- 旧记录只有 `video_metadata_excluded=true`、没有分类来源时，保守保留为“历史排除（来源未知）”，不猜测用户是否曾手动确认。
- 人工指定视频优先；人工排除和旧未知来源排除保持排除；人工补录数据优先于后缀规则；之后应用系统和自定义规则。
- 自动排除随规则撤销恢复资格，人工排除需显式恢复。已清理的元数据不会恢复旧值，会在后续采集中重新生成。

列表、计数、统计、候选、入队及执行前判断共享 SQL 规则，URL 查询参数不参与后缀判断，本地文件名中的 # 保留。采集写回前再次检查状态，避免整理/补录后旧结果回写；中途规则变动会释放 processing 状态。

## 验收

后端测试覆盖明确非视频、视频失败/缺失/临时后缀、未知后缀、URL、本地 #、人工覆盖、规则撤销、列表和统计一致性、405 条分批清理、写回保护与分集新增/编辑。
前端交互测试覆盖视频后缀提醒取消、未保存规则禁止整理、预览确认令牌、批量部分失败、切换视图旧响应保护。
