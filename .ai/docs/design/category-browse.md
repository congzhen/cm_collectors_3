# 文件库分类浏览

## 使用与配置

- PC 资源页右下角“显示设置”保留原有布局样式、配色和控件，将封面内容从尺寸与间距下方独立为一列，依次展示显示模式、尺寸与间距、封面内容、页面与交互；窄窗口自动换列，不使用页签。分类浏览独立放在尺寸与间距、封面内容两栏下方；开启和关闭时均横向保留分类来源、每组上限、封面与展开样式；关闭只禁用输入，不折叠表单，应用按钮始终保留。页面与交互保持右侧独立，上方两块卡片底边对齐，下方分类卡片与左右两侧面板底边对齐，统一使用 12px 间距。
- 通用显示设置保留原“保存”行为；分类浏览使用独立草稿和“应用分类浏览”按钮，通过专用接口只保存本库六个分类字段。失败保留草稿，切库后旧响应不能影响新库。
- 文件库设置也提供同一组字段。`categoryBrowseEnabled`、`categoryBrowseSource`、`categoryBrowseSort`、`categoryBrowseGroupLimit`、`categoryBrowseCoverStyle`、`categoryBrowseExpandStyle` 保持本库独立，不加入公共展示配置白名单，不影响已有资源关联组的样式和归属。
- 每组默认 12 个，允许 0～100 个；0 表示不限制、不拆组，1～100 按上限拆组。同一分类按资源排序拆成连续的小组，标记组号、本组数量和分类总量；随机排序时改用收录时间及 ID 稳定划分。
- “返回资源浏览”临时回到普通列表，底部“分类浏览”按钮可恢复；不改已保存的开关。重新应用分类设置也会恢复分类浏览。管理模式与移动版暂停此浏览方式。
- 分类浏览时，底栏片段按钮左侧提供“资源”按钮（宫格图标），用于返回普通资源列表；返回后该位置切换为“分类”，支持恢复分类浏览，保持原有单行底栏布局。
- 设置弹层保持原现代与旧版样式，内容区设置最大高度并可滚动，小窗口仍可访问分类设置和保存按钮。
- 显示设置中的关联组及合集封面／展开样式下拉列表保留在父弹层内，选择选项只关闭下拉列表，不关闭显示设置；点击父弹层外部仍正常关闭。现代、小窗口与旧版布局均验证可选且无裁切阻挡。
- 宽屏分类浏览卡片按内容高度收紧，多余高度由上方尺寸与间距、封面内容两栏承接，保持两侧面板底边对齐；窄屏换列时仍按内容自然排列。
- 分类分页和统计使用资源页原有底栏，与右侧快捷按钮保持同排；分类内容区不再单独显示分页栏。
- 普通及分类底栏统一采用图标＋两字文字：分类、独立、合并、片段、待播、显示，悬停或无障碍名称保留完整功能名；独立／合并继续保留在底栏。普通统计缩为“2496 资源 · 本页 100 项”，分类统计缩为“4 组 · 29 资源”，完整统计在悬停提示中查看。900px 以下隐藏本页项数与跳页输入，600px 以下隐藏统计摘要并缩小分页间距，按钮文字保持可见；极窄窗口允许底栏横向滚动。

## 归集与分页

- 全部查询沿用现有资源搜索、星级、国家、年份、清晰度、编码、演员和标签筛选。先对当前库的完整命中范围归集，再按展示组分页，不从资源当前页拼组。
- 演员来源使用资源演员关系，停用或已删除演员不作为分类；不通过演员标签推导作品，也不混入导演关系。标签来源必须是当前库启用的标签分类，成员依据该分类中启用的资源标签。
- 同一资源允许出现在多个分类中，但每个分类内部去重。资源总数按筛选命中资源去重统计，分类数量和展示组数量分别显示。
- 没有有效对应关系的资源进入“未关联演员”或“未设置分类标签”，固定放在末尾，也按上限拆组；空分类不显示。
- 分类排序同时支持演员和自定义标签：资源最多（默认 `count`，演员复用演员库的资源总量，统计演员库关联文件库内有效资源的演员及导演关系并去重；标签复用标签库的有效资源应用总量；总量相同按分类添加时间及 ID 降序）、名称顺序（`name`，名称及 ID 升序）、默认顺序（`default`，演员或标签自身添加时间及 ID 降序，后添加优先）。总量排名不受当前文件库及资源筛选缩小影响，但仅显示当前筛选有成员的分类，卡片数量、拆组及展开内容仍严格使用当前命中范围。先对全部命中分类排序再分页。旧配置缺失排序时使用资源最多；未分类固定在末尾，同类分组连续。组内排序仍复用资源排序并添加 ID 作稳定兜底；修改分类排序回到分类第一页。
- 封面摘要每组最多 7 个资源；展开读取本组全部资源，不额外分页；0 时读取整个分类，正数时每组最多 100 个。演员卡片保留姓名和可用头像。分类浏览每页最多 100 个展示组；不限量分类进入后沿用资源分页，不一次展示全部列表。
- 当前小组只有 1 个资源时，四种合集封面统一使用完整单封面，不保留叠牌缩进或重复主封面；按本组数量判断，不受分类总量影响。2 个及以上维持原构图，摘要尚未到达时的既有占位逻辑不变；分类信息、悬停预览和进入行为保持不变。
- 点击封面进入本组资源，另可进入整类资源并分页。组内沿用原资源列表的封面模式、详情、评星及播放功能，关闭推荐模块和资源关联组合并，避免展示或展开筛选范围外的资源。
- 返回分类列表保留进入前的页码；刷新后总量减少导致页码越界时，自动回到最后一个有效页。页码变化由单一入口查询，避免分页事件和状态监听重复加载。
- 组内刷新同步分类总量、分组数与本组数量；末组因删除或解除关联消失时，自动回到仍存在的最后一组。整类范围不自动切换，但保留切回有效本组的入口；整类为空时保留空状态提示。
- 上限、排序或资料变化后，小组内容可能顺延；这些是动态展示单元，不创建实体分组、复制资源或移动文件。

## 展示与生命周期

- 封面复用叠牌、三联切片、侧翻书页和自适应拼封；展开复用扇形手牌、横向封面带、折屏、书脊及杂志拼版。
- 分类内使用面包屑返回列表，以“本组／全部”切换范围。未拆组的卡片隐藏组号和“查看全部”入口，避免重复导航。
- 单个浏览牌组展开；悬停延迟展开、移入面板保持、移出延迟关闭，外部点击、窗口失焦或外部滚动收起；预览成员按原播放配置打开。
- 分类、筛选、文件库或每组上限改变时清除已进入的分类及旧页。所有请求校验版本；失败清空旧可操作内容并提供重试，切库或卸载后旧请求不能回写。
- 慢请求期间重复展开同一张卡片共用当前请求；分类变化会清除缓存与加载状态。页面首次挂载由分类组件加载，外部刷新回调等待分类数据返回。
- 分类保存与通用保存期间互相禁用，防止旧配置覆盖刚保存的分类设置；专用接口校验分类来源、样式和拆组上限。
- 底栏独立／合并切换与显示面板保存也互相禁用；切库或替换同库配置时解除旧请求的等待状态，并用请求版本及配置身份隔离旧结果、错误提示和最终状态。
- 分类加载开始时清除上一页或上一组的详情选择，避免导航后继续显示旧资源；时长补读不触发清除。快捷应用先校验每组上限与标签来源，标签加载期间提示等待；保存成功和失败均校验库、配置对象及请求版本。
- 分类封面摘要只查询展示必要字段；进入资源列表时沿用视频元数据补采，并在开启时长显示时延迟补读一次，只合并时长，不覆盖当前评星或改变列表顺序。

## API

- `POST /api/resource/categoryBrowse/summaries`：当前筛选的分类展示组分页和封面摘要。
- `POST /api/resource/categoryBrowse/members`：当前筛选的指定组成员；`part=0` 查看整类并按资源分页；每组上限为 0 时，`part=1` 一次返回全部预览成员，不接受更大的组号。
- `PUT /api/filesBases/setConfig/filesBases`：保留原通用显示设置的本库配置保存接口及公共配置跟随检查。
- `PUT /api/filesBases/categoryBrowse`：分类快捷按钮只更新五个本库字段，事务中保留其余原始配置，跟随公共配置时也能独立保存。

- 分类总量排名使用数据库子查询与一次聚合，避免逐批绑定分类 ID 和重复扫描；演员保留关联文件库范围及演员／导演资源去重，标签保留全量有效资源应用次数。17,000 个演员及标签回归覆盖总量排名、参数上限及同总量跨页稳定性。快捷分类设置在同库配置对象被等值替换时也重置旧保存状态，旧响应不会解除新请求的等待或覆盖新排序。
- 封面摘要在每组上限 1～16 时合并同分类连续小组的查询，临时读取范围不超过 256 个轻量封面记录，每组响应仍最多 7 张；较大分组与不限量分类仍只取本组前 7 张。空命中范围提前结束。回归覆盖上限 0／4／12／16／17／100、第一页及后续页、演员及标签摘要顺序。

- 优化后增加独立成员列表对照：演员／标签来源、资源最多／名称／默认顺序、星级／演员／标签筛选，上限 0／1／7／8／12／16／17／100，以及第一页、第二页、末页和越界空页。逐项核对分类、组号、分组数量、封面 ID、图片尺寸及摘要字段范围；模拟 API 浏览器验证封面与展开样式、分页及返回恢复。本轮未发现速度优化引入的排序、分页或封面回归。
