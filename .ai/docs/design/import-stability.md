# 批量导入稳定性与自动备份协调

## 范围

主前端 `cm_collectors_html` 扫盘导入仍由浏览器逐条发起请求，每条单独入库。没有增加持久化导入队列；关闭页面不会继续派发，重启不会自动续传。

## 导入结果与资源限制

- 所有导入查找均限定目标文件库；同库导入请求串行执行，避免多窗口或计划任务重叠时重复创建资源／分集。等待可取消，并计入单条请求预算。追加模式会在实际处理时再次去重，已存在项跳过并返回提示。此协调不覆盖其他手工编辑接口或多服务进程共享数据库。
- 覆盖导入已有文件时保留原资源归属，不再重复追加到同目录其他资源。相似名称合并检查同目录全部资源组，再选择匹配组；文件夹合并仍选择第一组，且同时开启两种合并时文件夹模式优先。
- NFO 导入遵循自动添加标签、自动添加演员和匹配演员别名三个开关；关闭自动添加仍可关联已存在项。非 NFO 调用方继续沿用原有自动创建和别名匹配行为。
- 新前端先登记批次，单条请求携带 `batchId`；成功返回 `warnings`。不携带批次的旧客户端仍收到布尔成功结果。
- 状态区分等待、处理、成功、警告、失败和结果待确认。成功及警告均表示已入库；网络中断或 HTTP 5xx 不推断入库结果，也不自动重试当前文件。需重新扫描核对。
- 事务已提交后的详情读取失败，或分集已写入后的排序等后续步骤失败，返回已入库警告，不标为可重试的普通写入失败。
- NFO 支持带属性文本和重复文本节点，无法识别的字段保留原值并报告警告。NFO 最大 8 MiB。
- 本地封面和演员图片最多 32 MiB、2400 万像素。目标裁剪尺寸最多 400 万像素；直接从原图裁剪区域缩放，不生成原尺寸 RGBA 裁剪副本。原图模式保留压缩文件字节，不强制缩小本地封面。
- 封面处理失败：新资源使用默认封面并返回警告；覆盖导入保留旧封面及其尺寸、类型，探测未得到新清晰度时保留旧值。无匹配封面且未开启生成时正常使用默认封面。
- 自动封面保留 `thumbnail=100`，先等比例缩到不超过 400×600，再缓存候选帧。全局封面提取并发为 1；排队与执行共享 20 秒预算，图片输出最多 8 MiB，错误输出最多保留 16 KiB。
- 导入清晰度探测最多 20 秒，并将成功结果写入现有短期视频信息缓存，供紧随其后的后台采集复用。缓存过期后仍可能重新探测。
- HTTP 单条导入上下文预算为 60 秒；前端请求超时为 90 秒。取消传递到外部进程，入库前再次检查上下文。普通本地文件系统读写不能保证被上下文立即打断，已提交事务不因取消回滚。

## 自动备份协调

- 服务端批次租约为 90 秒，前端每 20 秒续期。结束主动释放；断线未释放的租约自动过期。
- 在途单条导入与计划任务整个导入循环另有活动计数，即使租约过期也保护正在执行的操作。多个任务需全部结束。
- 数量阈值、定时触发仍记录待执行备份需求，导入期间不准入新自动备份；执行前重新检查阈值与时间条件，避免手动备份或设置变更后执行过期触发；停止导入后至少等待 30 秒空闲窗口，队列检查周期可能使实际等待更长。
- 已准入备份继续执行，手动备份不经过导入门禁。备份完成只扣除开始时已累计的变更，保留运行期间新增的计数。
- 自动备份状态表由既有模型初始化迁移，不再在每次资源变更时调用 `AutoMigrate`。
- 旧客户端没有整批租约，只能保护单条在途请求及其后的空闲窗口；完整行为需要前后端同时更新。

## 验证

- 前端组件测试：320 条混合结果汇总、连接中断、主动取消、心跳失败、配置快照。
- Windows 配置组合集成测试：`go test -tags=importstress -vet=off ./processors -run '^TestImportConfigCombinations$' -v -count=1 -timeout=120s`，须在服务端目录单独执行。49 个场景使用隔离 SQLite 覆盖命名、封面匹配和裁剪、追加/覆盖与合并组合、排序、NFO 开关及匹配、创建和别名开关、探测失败保留旧清晰度。新增交互验证包括主/关联演员库搜索、开关四种组合、旧函数兼容、无主演员库、文件夹合并优先级、纯集数合并、目录隔离，以及覆盖时更新 NFO/封面并保留分集和已有标签/演员关联。2026-11-14 全部通过；当前测试环境无 ffprobe，成功探测不在本轮验证范围。
- 后端：多批次、租约过期、在途保护、空闲窗口、备份计数、NFO 类型兼容、图片大小及像素限制、原图保真、裁剪位置、截断 JPEG、输出缓冲和取消。
- 可用 FFmpeg 时，用临时合成视频验证真实封面输出和超时；不启动服务或访问业务数据库。
- 6000×4000 JPEG 裁剪到 400×600 的单次分配基准约 35.3 MiB，原实现隔离测量约 76 MiB。此数值为分配量，不代表进程峰值或完整批量导入测试。
