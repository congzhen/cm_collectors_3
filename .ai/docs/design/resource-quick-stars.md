# 资源快捷评星

## 范围

- 主前端桌面资源列表支持点击及鼠标按住横向拖动评星，松手保存；悬停仅预览。使用现有 `stars`，1～5 星整数，清除写入 0，不修改 `score`。
- 文件库显示设置增加 `resourceQuickStars`，默认关闭，保持本库独立，不加入公共展示配置白名单。关闭不清空已有星级，不影响原有封面评星标签。
- 手机不提供此快捷入口，包括手机切到桌面显示时。写入沿用现有管理员权限，访客只读；资源管理选择模式不显示快捷入口。

## 布局与交互

- 所有封面模式统一使用封面右下角、标题上方的小星级入口，鼠标移入卡片或键盘聚焦时显示；未评星显示空星，已评星显示星形及数字。不在卡片下方或信息区增加快捷评星行。
- 入口放在封面自身的定位容器内，各显示模式按标题及原视频时长位置设置底部偏移。存在时长或关联组数量角标时，入口在角标上方再留出 28px，避免遮挡；角标保留原位置。移除顶部属性标签的宽度预留及局部避让，标签恢复原宽度和 flex 排版，悬停不改变标签位置。
- 封面评星浮层优先向上展开，空间不足时自动换向；表格入口保持原位置及向下展开方式。浏览器模拟接口检查 12 种封面模式，覆盖时长开启／关闭、入口在封面内部及与时长无重叠，并对比快捷评星开关前后的标签位置一致。
- 悬停入口 150ms 展开独立浮层，展示当前资源名、五颗星和清除入口；浮层传送到页面外层，靠近屏幕边缘时自动调整位置。移入浮层保持展开，离开 250ms 后收起；拖动和键盘操作期间保持，Escape、外部点击、窗口失焦及列表滚动收起。一次只展开一个评星面板。
- 浮层采用两层紧凑布局：顶部为截断资源名与当前星级状态，底部为独立浅底操作区。未选星为空心轮廓，选中为金色实心星；清除使用文字按钮，不再显示常驻操作提示。
- 表格复用评星列，显示小星级入口，悬停或点击展开同一面板。按钮支持键盘操作；清除入口独立于星星，避免重复点击导致误清空。
- 评星操作阻止点击事件冒泡，避免打开详情或播放；同资源保存期间禁止重复提交，指针取消不保存，失败恢复原值并提示。
- 窗口失焦、Escape 和组件卸载均取消拖动；控件被隐藏或宽度无效时不提交星级。进入评星区域关闭关联组悬浮面板，避免遮挡操作。
- 鼠标从评星入口直接移回同一卡片封面时恢复关联组展开，不要求离开整张卡片。
- 管理选择模式统一关闭快捷评星，表格和宽图卡片恢复原有只读星级展示。

## 保存与同步

- 复用管理员 `PUT /api/resource/batchSetStars`，只传当前资源 ID。
- 保存成功同步当前挂载的资源副本，包括列表、推荐模块和详情；按文件库及资源 ID 区分，不保留跨刷新评分缓存。
- 不重新查询列表，因此星级排序和筛选在下一次查询时生效，当前资源不立即跳位或消失。
- 切换资源或文件库后，旧请求只能更新其所属资源，不能覆盖新资源的预览状态。
- 切库后尚未刷新的旧资源卡片不能发起新的评星写入。
- 翻页卸载后，旧保存成功仍同步当前挂载的同资源副本；已卸载副本不再跟踪。切库或卸载后的旧请求失败不在新页面弹出过期错误。
- 同资源共享保存锁，但悬停预览由各控件独立管理；只有发起保存的控件保留提交中的预览，其他位置移开鼠标后恢复真实星级，避免成功或失败后残留未提交的预览。

## 验证

- 前端全量 472 项单元测试通过，包括 14 项评星保存专项测试、3 项浮层交接与关闭测试，以及关联组悬停回归。
- 生产构建通过；类型检查仅剩已有 `testCase_contentMenu.vue` 中的 `require` 类型错误。
- 后端公共配置相关测试通过，验证缺省关闭、开关独立于公共配置，以及跟随中允许保存本库开关。
- 使用临时 Vite 页面、模拟 API 和无头 Edge 验证全部 13 种模式的封面锚点、浮层移入和移出、保存与清空；真实鼠标拖动松手仅保存一次，Escape 可在编辑器内收起面板，不触发资源打开；小窗口浮层保持在屏幕内。手机设备限制沿用此前验证的判断。未写入现有数据库。
