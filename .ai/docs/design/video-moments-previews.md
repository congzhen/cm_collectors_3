## 用户入口

- 资源详情的收藏列表确认无记录时隐藏整个区块（含标题和外层留白）；保留组件订阅，新增第一条后自动显示，删除最后一条后自动隐藏。首次读取失败则保留错误和刷新入口，重试成功确认空列表后再隐藏；切换资源时清除旧错误并忽略旧响应。
- 资源详情：演员下方、剧照上方直接列出当前资源的片段收藏；桌面顶部不再显示收藏入口。手机首页保留全库片段收藏入口。
- 桌面片库底部“片段收藏”：右侧抽屉列出当前库收藏，支持按片段名称、备注、资源标题搜索，每页 50 条并显示总数。播放复用现有弹出式播放器，直接传入起止点并循环；列表保留方便继续选择，切换文件库时关闭抽屉和播放器。
- 内置播放器右上角：片段 / 预览。支持收藏当前时刻、标记起点和终点、编辑名称与备注、删除记录、跳转与片段循环。
- 资源详情和手机播放页：只直接展示收藏列表；画面时间轴统一放在播放器的“片段 / 预览”面板。
- 片段新增、编辑或删除成功后，当前页面收藏列表自动刷新；缓存页面重新进入时读取最新列表，卸载时取消订阅。
- 桌面播放进度条悬停、手机播放进度条拖动：显示已生成的预览图片。
- 片段循环时，进度条完整长度对应收藏起止范围，时间、拖动和预览按片段计算；桌面时间旁、手机控制条上方显示循环信息并随控制条隐藏。进入时使用原有 UI 消息提示 2 秒，退出后恢复整部视频的进度条和时间。原生系统控制条无法插入控件时使用可隐藏的片段进度提示。
- 设置 → 软件设置 → 视频预览缓存：设置图片宽度、缓存容量上限，查看占用，暂停/恢复队列，清空缓存。

## 保留与删除规则

视频替换、移动、删除均不会触发预览自动失效、重建或删除。已有预览仍可查看。用户需要更新画面时，先在时间轴手动删除预览，再生成。

缓存容量淘汰是独立规则：默认上限 1024 MB，0 表示不限，非零至少 64 MB。保存容量设置、每个生成任务结束时检查容量，按最早完成/更新时间删除缓存，直到不超过上限；不删除视频或片段记录。正在生成、排队中的任务不参与淘汰，因此生成期间可能暂时超过上限。

修改图片尺寸、抽图间隔不会重建已有预览，需手动删除后重新生成。清空全部缓存需要当前队列不在执行；运行时先暂停，等待当前一帧结束。单个排队任务可在队列暂停并停止执行后删除。

片段仅记录播放位置，不是视频副本。源文件不可用时保留名称和备注，播放入口禁用。更换视频不会因文件指纹变化禁用收藏。

## 实现边界

- 主前端 Vue 3 与 Go 服务端；不改 Wails 前端、APK 或服务端内嵌构建目录。
- `video_moments` 保存分集、资源关联及起止秒数。`end=0` 表示单个时间点。
- `video_previews` 保存任务状态、抽图间隔、进度、尺寸和缓存目录标识；`video_preview_settings` 保存全局缓存配置。
- 迁移 ID：`video_moments_previews_v1`，只建表，不扫描现有视频。
- 预览图片保存在 `runtime/cache/videoPreviews/`。按 10/30/60/120 秒抽图；单视频最多约 1200 张，超长视频自动加大间隔。宽度支持 160/240/320/480 像素，默认 240。
- 单 worker 顺序生成图片，单帧超时 45 秒；暂停在当前一帧完成后生效。失败可重试。服务重启后的残留处理中记录，在首次队列操作时转为排队；点击恢复继续。
- 按文件库的生成方式排队：默认内置播放器实际开始播放时自动生成，也可设为手动点击；新增、编辑收藏均不触发生成。进度条使用时间轴中对应区间的预览图；收藏首图独立截取片段起点并保存在 db/videoMomentCovers，不依赖时间轴缓存。
- 列表每页 50 条。手机普通播放时使用页面浮层；全屏播放时面板留在播放器内。
- 数据沿用现有搜索收藏的共享模式，服务端统一保存，不按设备隔离。缓存设置、全部清空和队列管理要求管理员权限。
- 第一版支持本地视频和内置播放器。外部播放器不提供片段循环控制；网络链接不进入 FFmpeg 预览队列。

## 收藏首图与时间轴缓存分离

- 收藏首图保存到 db/videoMomentCovers，使用独立 /videoMoments/:id/cover 接口。保存收藏时截取开始位置；已有收藏首次请求首图时补生成。已有首图不随视频替换而更新，时间轴缓存的清空、淘汰或手动删除均不影响首图；删除收藏才删除对应首图目录。
- 时间轴仍保存到 runtime/cache/videoPreviews。读取任务状态时检查已完成图片是否存在，检测到图片缺失或零字节则返回 missing 状态、隐藏失效帧并允许重新生成；重新排队清理残留帧并重置进度。自动模式下再次开始播放也可重新排队。
- 检查只针对缓存文件丢失，不比较源文件指纹来使已有图片失效；没有恢复旧缓存自动迁移逻辑。
