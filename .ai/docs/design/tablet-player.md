# 大屏移动设备播放器

页面布局仍使用原 mobile.ts，不改变首页、漫画、图集、手机页面或外部播放方式。桌面视频独立页和弹窗通过 resourceVideoPlayer.vue 复用手机播放器。

后台通用设置：largeMobilePlayer 默认 desktop，可选 mobile；largeMobileShortSide 默认 768；largeMobileLongSide 默认 1024。尺寸为视口 CSS px，允许整数 320–4096，短边不得大于长边。移动设备任意一边达到阈值即使用大屏策略。桌面 UA 的 iPadOS 通过 MacIntel 与多点触控识别；桌面电脑不因尺寸或触控而命中。

播放器仅由后台设置决定，播放区域不提供本设备选择，也不读取旧的本设备播放器偏好。手机页面及列表内嵌播放器保持原行为。

每次打开时确定播放器类型，旋转、分屏、切集及后台配置更新不会切换当前播放器。关闭弹窗销毁播放器。移动播放器继续负责视频源、字幕、续播、横屏和手势。closeMobileDisplay 只影响页面布局。

PC 播放器全屏时，触摸开始或滑动可唤出控制条；手指操作期间不隐藏，全部手指离开或触摸取消后恢复自动隐藏。采用捕获阶段的被动监听，不阻止子控件的点击、进度或音量拖动。

自动验证覆盖尺寸边界、设备类型、非法配置、忽略旧偏好、模式稳定、切集请求隔离及触控唤醒。真机需验证 Android 平板和 iPad 的独立页、弹窗，横竖屏进度拖动、全屏手势、退出全屏、切集、字幕、续播及关闭停止播放。
