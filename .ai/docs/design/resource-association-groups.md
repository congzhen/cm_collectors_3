# 资源关联组

## 范围和交互

- 一组只关联同一文件库中的资源，一个资源最多属于一组，每组最多 1000 个资源。没有组名、虚拟资源或文件移动。
- PC 主资源列表按当前页数据合并；保留原始搜索、筛选、排序和资源分页语义。同组的第一个命中成员占据原来的位置，跨页可以重复出现同一组。
- 叠牌通过主卡片缩小至 92%、后两层封面在原卡片内错位实现，不扩大原卡片的宽高。即使本页只命中一个成员也展示叠牌。
- 悬停按需加载整组。组内成员点击统一执行播放/打开动作，不受详情显示设置影响；短视频布局使用内嵌播放动作，页外成员不插入可见列表。
- 浏览悬浮层采用透明背景的扇形手牌，与原资源叠牌重叠展开；整组全部渲染，始终单行，不分页、不显示底部说明。按可用宽度和成员数持续压缩间距，超过 7 张缩小封面，不再按数量换行。指针或键盘焦点移入时，对应封面抬升、转正并置顶，邻牌按距离排列层级。管理面板继续提供排序、移出和解散操作。
- 手牌封面等比铺满容器（cover），裁切多余边缘，不留黑边；标题叠加在封面底部渐变上。明亮、暗黑主题分别设置牌框、底色和阴影。密集排列时按指针横向位置切换置顶牌，避免被邻牌遮住后无法选中；浮层在两个方向避让屏幕边缘。
- 展开状态由原资源和浮层统一控制：进入延迟 180ms，离开两者后延迟 400ms 收起，重新进入取消收起；切换资源、卸载、点击外部、失焦或按 Escape 时清理状态。加载态预留牌组高度，减少加载完成后的位移。指针定位按牌间距直接计算，不逐张读取布局，并为相邻牌切换加入缓冲，避免边界抖动。
- 加载态根据组摘要中的成员数预留与完成态相同的高度；全局只保留一个展开的浏览牌组，关闭或卸载时释放归属。键盘使用左右方向键逐张切换，Home/End 到首尾，仅当前牌参与 Tab 顺序，避免大组产生大量 Tab 停留点。
- 鼠标点击时重新按点击坐标定位，覆盖浮层在静止指针下出现、尚未发生 pointermove 的情况；键盘激活使用焦点资源。外部页面滚动时收起浮层，内部滚动保留，窗口缩放时重新计算原资源的重叠偏移。关闭动画结束后卸载手牌封面节点，保留面板内的成员数据，再展开无需重复请求。
- 首次挂载或重新定位可能产生没有实际指针移动的离开通知，关闭计时结束时必须复核指针是否仍在原资源/浮层矩形内，键盘焦点在内部时同样保持展开；展开期间跟踪文档指针移动，确保真实移出后仍会收起。滚动通知仅在原资源位置确实变化时收起，避免初始化布局或焦点设置引发的滚动通知误关。
- 本库独立字段 `resourceGroupExpandStyle` 支持 `fan`（默认扇形手牌）、`strip`（横向封面带）、`fold`（封面折屏）、`spine`（纵向封面书脊）与 `magazine`（杂志拼版）。显示设置中间列的“封面内容”卡片底部以及文件库配置均可选择，沿用本库配置保存，不进入公共展示字段列表。横向封面带封面保持竖直，默认紧密叠放，牌间距最多 48px，整体宽度按约 40px 的增量随成员数增长，最多 640px；指向成员轻微抬起置顶并显示标题，其余牌隐藏标题。命中区域按固定间距计算，视觉抬升不改变命中区域。五种样式共用首次展开保护、明暗主题、等比裁切及统一播放入口。
- 封面折屏默认展开原资源，整个连续画面只保留外侧圆角和整体阴影。成员之间以自适应细缝分隔，选中成员展开、其余收窄，首尾展开均保持在组件内；固定等分命中区不随宽度动画改变。鼠标静止时滚轮可逐张浏览，方向键/Home/End 可精确切换，视觉动画或静止指针不抢回选择。统一在容器处理按下和点击，保证点击细缝或动画期间命中不同切片仍可打开锁定的目标。观察容器宽度变化重新布局，卸载时清理 ResizeObserver。浮层沿用原有边缘避让，整块向屏幕内侧平移，不在左右边缘改变造型。
- 纵向封面书脊复用折屏的稳定命中、锁定点击、滚轮和焦点同步机制，改为按纵向等分区域选择，使用上下方向键与 Home/End。收起的横向书脊只显示裁切封面，当前成员向上下展开封面并显示标题。整体宽 320px，高度按成员数增长、最多 520px，并受可用视口限制；以实际展开时的鼠标位置为虚拟锚点贴近展开，轻微覆盖鼠标附近，避免宽卡片侧边离光标过远；靠右向左避让，空间不足时整体移入屏幕。开点在展开前跟踪、展开后固定，不随鼠标移动。加载态沿用摘要成员数预留高度，方向切换清理指针和按下状态；设置项采用名称与下拉选择器同排的单行布局，五种样式在下拉菜单内选择，保留扇形默认值。
- 密集定位使用实际矩形宽度及计算样式中的小数牌宽，避免 clientWidth/offsetWidth 取整后偏到邻牌；鼠标按下时锁定精确目标，click 沿用该目标，避免浏览器对 click 坐标取整再次产生偏差。取消指针操作或成员变化时清理按下目标，键盘仍按焦点资源激活。浏览器验证包含 503/900px 窗口宽度、两种样式及 3/40/1000 个成员的首尾与中间点选。
- 列表资源或组摘要更新时标记成员缓存过期，当前展开保持稳定，下次展开重新读取，避免长期显示旧标题、封面或成员。解散确认绑定发起时的文件库和组，确认期间切换或卸载后不继续提交。整组读取沿用普通详情的关联数据及本库演员/导演资源数量统计。
- 历史记录、热门、随便看看等推荐模块、移动端、表格和管理模式不合并。
- 三种短视频布局的播放候选均校验当前文件库归属；切库后即使父列表暂时保留旧数据，旧页和页外组成员也不能重新加载播放，新库列表到达后再恢复正常播放。
- 三种内嵌短视频布局提供保留展开状态的上下文，点击组成员只切换播放器，不收起牌组，也不因组内切换自动滚动列表；移出、点击外部、Escape、切库仍沿用正常关闭。普通布局选择成员后收起并执行播放/打开。牌组内部方向键停止冒泡，避免与播放器快捷键同时触发。
- 五种展开样式共用一个组内播放入口：布局提供播放动作时使用该动作，否则默认 `playResource`，沿用资源类型和播放器配置；不再根据“无/右侧/弹出详情”分支判断。拼贴布局的原播放按钮和组内点击复用同一播放方法，播放器模式切换内嵌视频。原资源卡片的详情点击行为保持原样。
- 折屏已在内部持有键盘焦点时，鼠标或滚轮切换会同步焦点，Enter 始终对应当前预览；外部焦点不被抢走。整体边框使用不占布局空间的装饰层，保证宽度测量与切片排列一致，避免首尾裁切。

## 管理

- 多选至少两个未分组资源直接创建；原组成员和未分组资源共同选中可直接加入此组。
- 管理模式保持平铺，卡片和表格显示本页组号；同组同色，不同组按八组背景色、文字色和边框色循环。
- 未分组资源可从组选择面板加入已有组，默认仅显示本页出现的组，可切换到同库全部组查看其他页；按成员名称、副标题或番号搜索。
- 选组发起加载时清除旧候选，加载或提交期间禁用候选与分页；翻页加载失败只保留错误和重试入口，避免继续操作上一页的组。
- 选择某组成员后可以打开整组面板，移出成员、调整顺序、添加成员或确认解散。
- 添加成员可以保留目标组、清空选择后继续在当前布局勾选。不同已有组不自动合并。
- 解散只解除关系；组内不足两个成员时自动解散。删除成员或将成员移动到其他库时也清理关系。

## 保存与配置

- `resources.association_group_id` 保存组 ID；`association_group_sort` 保存面板内成员顺序。`resource_association_groups_v1` 迁移补齐字段和索引，旧资源默认为未分组。
- 所有关联变更在数据库事务内校验同库和单一归属，行锁及条件更新防止覆盖其他组归属。
- `mergeResourceGroups` 是文件库独立显示配置，缺省开启，不在公共配置白名单中。
- 文件库设置和分页开关共用配置；分页通过专用字段更新接口保存，避免修改公共配置或跟随状态。
- 分页仍显示资源总数，并在合并生效时显示本页展示项数量。管理和表格模式只暂停合并，不改保存值。

## API

- `POST /api/resource/groups/summaries`：当前库分组摘要；指定 groupIds 时批量获取，否则按组分页，支持成员文字搜索。
- `GET /api/resource/groups/:filesBasesId/:groupId`：整组成员，沿用普通资源读取范围。
- `POST /api/resource/groups/manage/:action`：管理员 create / add / remove / reorder / dissolve。
- `PUT /api/filesBases/resourceGroupDisplay`：管理员仅修改当前库 mergeResourceGroups。

## 验证

模型测试覆盖组生命周期、跨库/多组冲突、删除/移动清理及失败回滚、独立配置和旧资源迁移、批量摘要超过 20 组不截断、全库选组分页和番号搜索、整组详情的分集排序及本库演员数量。前端覆盖当前页合并、原列表还原、鼠标/管理操作、配置保存失败和切库隔离、三种短视频布局连续选择页外成员、缓存过期后重新展开、解散确认期间切组或卸载。隔离浏览器使用模拟封面验证海报、瀑布流、拼贴和紧密墙的叠牌边界，并操作悬停选择与点击创建，不启动真实业务服务。

- 杂志拼版以当前资源为主封面，前五项组成固定主副版式，其余资源在同一浮层续排；悬停只改变图片亮度、内部缩放和标题，不改变格子位置。整体宽 560px，超过五项时高度 460px，否则 300px，受视口限制；窄窗口采用纵向拼版。使用原生内部滚动及 overscroll-behavior 避免滚动传递，全部成员可达。跟随首次悬停位置展开后固定锚点，边缘由浮层翻转和避让；方向键、Home/End 支持聚焦并只滚动浮层。沿用短视频连续切换与其他模式统一播放行为。

- 本库独立字段 `resourceGroupCoverStyle` 控制未展开时的静态封面：`stack`（默认叠牌封面）、`triptych`（三联切片）、`book`（侧翻书页）、`adaptive`（自适应拼封）。在显示设置“封面内容”中位于展开样式上一行，文件库设置也可修改；不进入公共配置白名单，与展开样式独立保存。旧配置缺省沿用叠牌。
- 三联切片与侧翻书页由 `ResourceGroupCover` 复用组摘要封面：排除当前资源后最多取两个成员，两个成员只露一片，摘要加载中以当前封面预留一片。三联切片主图宽 70%，右侧等分窄片；书页主图宽 90%，侧页带内收圆角和折光阴影。封面图片保持比例裁切，全部在原图容器内，不更改卡片尺寸或复制标题、按钮、播放器。仅本页合并组生效，管理模式、推荐和移动端维持原显示。主图 load 事件透传，保留瀑布流和短视频图片加载后的布局计算。

- 自适应拼封最多七张（主封面加六张辅封面），摘要查询上限从三张提高至七张，沿用组内排序，不为每张卡片追加成员请求。两张为左右主辅，三张为主图加上下两辅；四张右侧上方一张、下方两张；五张右侧田字格；六张右侧前四张田字格、末张横跨底行；七张右侧两列三行。多于七个成员仍用七张构图，展开后全部可达。主图占比依显示张数为 65% / 60% / 55%。
- 自适应拼封仅按组成员数量切换版式，七个及以上固定主封面加六张辅封面，紧凑或矮宽封面不再自动降为三张、五张。所有格子在原封面内等比裁切缩放，无需尺寸观察器，避免同一组因卡片大小而改变数量构图。自然尺寸占位图保持原图比例，避免自动高度封面在网格内发生百分比高度循环。

- 合并组封面在现有时长角标前显示组图标和“n 项”，数量取组摘要 count，不使用本页或预览数量；无时长、非视频或关闭时长显示时仍单独保留组数量。仅主列表合并组启用，平铺、管理及推荐区域不展示；角标内优先保留数量，时长过长时省略，沿用各布局已有角标位置。

- 翻页由 ContentView 在既有列表加载阶段预取当前页组摘要，与资源列表同一批发布，避免先显示临时双封面，再切到真实六/七张拼封。contentList 以库 ID、资源 ID 和组 ID 校验预取页，匹配时不重复请求；独立使用的列表仍支持自行取摘要，刷新期间保留同库同组已有摘要，切库立即隔离。摘要失败不阻断资源展示。
- 开启时长后的 2.5 秒补采只按资源 ID、分集 ID 更新 durationSeconds，保留列表、资源、分集及组摘要的对象引用，不重建卡片、不重新请求摘要；请求版本和文件库校验继续阻止旧请求覆盖当前页。普通海报列表按资源 ID 建立节点身份，避免翻页按序号复用旧资源卡片。

- 整体回归补齐普通封面瀑布流的统一组封面入口，主图 load 事件继续触发瀑布流 renderer。选组候选只取摘要前三张绘制叠牌，避免七张摘要越界遮挡文字。组操作期间禁用查看分组入口；旧库/旧组操作失败不向后来切换的界面提示。后台时长补采失败保留现有列表和时长。
- 组摘要预览改用只包含 ID、库 ID、标题、副标题、封面尺寸/路径、组 ID 和排序的轻量结构，不序列化资源完整字段中的空标签、演员、分集或播放状态；组详情接口保持完整播放数据。

- 连续操作回归：当前最新列表请求结束后统一解除初始化锁，初始化失败或被刷新请求取代时仍可继续翻页；已排队的时长补采执行前复核开关，关闭后不再额外请求。三种内嵌视频布局在没有当前视频时优先恢复已选组成员索引，避免无可播放分集的成员在后台数据更新后被首个视频替换；主动选择其他视频仍正常切换。

- 播放地址失败回归：三种内嵌视频布局不向播放器提交空地址；当前请求失败时清除播放占用标记，允许再次点击同一组成员重试。索引监听与显式点击共用请求序号去重，一次点击只发起一次加载；旧请求失败不清除新成员状态，网络异常被捕获并提示重试。
- 显示设置保存以提交时配置快照为准，等待期间防重复提交；失败保留当前选择，可重试，不重新初始化文件库。返回结果按库、配置对象和保存序号校验，切库立即取消旧界面的等待状态，旧请求不能提示或覆盖新库。保存中继续编辑时保留新选择，并提示后续修改需再次保存。

- 普通短视频、上下短视频的普通卡片点击与组成员选择共用播放入口，补齐同卡片重试与无分集时停止旧视频的行为，保持后台刷新后的当前选择。普通短视频方向键沿用拼贴播放器的交互边界：管理模式、已消费事件、组合键、按钮/菜单/弹层及可见浮层不触发全局切片，普通方向键继续切换资源。

- 普通卡片沿用原有翻页后的上下项导航与点击滚动，只有组成员选择保留页外播放缓存。上一项/下一项同样更新当前资源选择，防止地址加载失败后后台刷新恢复更早的点击目标。
